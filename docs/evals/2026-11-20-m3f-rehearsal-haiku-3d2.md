## Assumptions and limits

- IT minutes saved per correctly answered ticket (assumptions, not measurements): own_username 5, self_described 8, how_to_guide 10. Hand-offs save nothing here, and a wrong answer's follow-up is not subtracted.
- Same-day repeats of an own-username request are expected to be answered: the month plants a second request only, and the verification ladder acts on up to 3 requests for one account in 24 hours (ADR-043). The ladder is not run here; the repeats are counted apart above.
- The reset signal is code only: it costs no model call and can only send a ticket to a person. A reset it misses falls back to triage and the picker.
- Every sender is a verified employee: identity binding is not part of this eval.
- Model calls: guide_pick 199, howto_gate 489, own_account_check 120, triage 900. Cost from the reported tokens: $0.1576.
- Prompt cache on: each call's system prompt is cached for 5 minutes. Input tokens: 85,961 at the full rate, 5,437 written to the cache and 1,956,703 read from it (96% of the input was read from the cache).
